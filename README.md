# Embodied Arm Studio

面向具身智能课程的机械臂仿真学习平台。你可以阅读中英文教材与交互图示，在课程项目中调整参数和奖励，运行 S1 机械臂仿真实验，查看指标、视频和评估结果。

- **学习与实践**：课程、教学班、项目工作区，以及可选的教学助手。
- **仿真实验**：固定控制演示和 PPO 训练，支持按课程配置开展实验。
- **结果分析**：运行记录、指标曲线、录像、模型权重与评估报告。
