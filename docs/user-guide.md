# 使用指南

使用维护人提供的平台网址和分配给你的账号登录；自行安装时使用启动引导中创建的账号。平台密码与 GitHub 令牌无关。忘记密码或看不到课程时，联系维护人核对账号和教学班。

## 阅读课程与进入项目

1. 在“入门学习”中阅读教材章节，结合交互图示理解机械臂、控制与强化学习的基本概念。
2. 打开“课程与高级任务”，选择组织、课程和教学班。
3. 进入教学项目，先阅读任务目标、成功条件、参数范围和训练预算。项目可见性及编辑权限由课程角色决定。
4. 在“任务与技能”中查看可用仿真任务。以页面标出的可运行状态及匹配的课程项目为准。

已有平台的数据由其维护人管理；新安装不会自动带入他人的历史实验、录像或训练权重。

## 配置一次实验

Core 模式可用于课程阅读和项目编辑。下面的真实仿真操作需要平台已启用 GPU 模式；共享 GPU 的使用时间按团队约定协调。

先区分两类运行：**Demo** 使用固定控制器演示动作，不进行策略学习，也不生成训练权重；**TRAIN** 执行策略训练，按任务生成指标和制品。

在项目的实验配置中选择任务，先使用课程推荐设置，再按学习目标调整：

| 设置 | 如何使用 |
| --- | --- |
| 场景与目标 | 查看初始位置、目标位置及动作范围，确认与当前课程任务一致 |
| 训练预算 | 按课程设置训练步数；增加预算会延长运行时间，不保证成功 |
| 随机种子 seed | 记录本次种子；比较参数时尽量使用相同种子和场景 |
| 奖励项与权重 | 在允许编辑的项目中一次调整一项，保存并检查后再运行 |
| 视频记录 | 按需开启；分辨率和帧率越高，渲染与存储开销越大 |

页面锁定的成功距离、保持步数等设置由任务合同决定。调整奖励权重时，先看该项的含义、正负号和示例；更高的奖励数值不必然对应更好的动作。

确认项目、任务和参数后点击启动，保留生成的运行记录（Run）链接。等待该记录更新，避免重复点击产生重复实验。教学助手可用于解释参数、奖励项和代码；涉及项目修改时按界面查看差异、确认应用，并可使用快照回滚。外部模型服务是否可用由平台配置决定，不影响阅读课程。

## 观察运行与指标

进入 Run 页面查看状态、训练进度、PPO 更新次数和指标曲线。`queued` 表示等待执行；`running` 表示执行中；`finalizing` 表示正在评估或整理制品，可能需要继续等待。

`completed` 表示流程完成。判断策略效果，还需结合完整评估结果、目标距离、成功率和视频中的实际行为。loss、总奖励或某一段成功录像都不能单独说明策略已经学会。

比较实验时保持任务、场景、预算和种子尽量一致，并记录修改的参数。训练步数较少时，策略可能尚未成功。Push 当前课程标准为 100 回合成功率至少 80%、Wilson 95% 下界至少 70%；其它任务应使用其各自的成功条件。一次固定场景的结果不能直接推广到其他场景或任务。

需要提前结束时，在原 Run 页面使用停止操作并等待终态。关闭浏览器或直播窗口不会停止训练。

## 观看直播与录像

运行期间可在 Run 页面观看实时视频；训练完成后，在同一页面查看可用录像和评估回放。录像支持播放、拖动进度和重新打开。直播与录像使用不同连接方式，录像可播放不表示直播网络已连通。

训练录像用于检查运行过程；成功回合回放用于观察选定的评估回合。没有成功回合时可能只有训练录像，具体以本次制品列表为准。Demo 不产生训练权重。

视频打不开时，先查看同一 Run 的状态与错误，再检查登录和网络；远程直播连接见[部署说明](deployment.md#远程访问)。向维护人提供 Run 链接、发生时间和去敏错误信息即可。

## 查看评估与下载结果

在 Run 页面及“运行制品”中选择对应记录，查看已登记的配置、指标、日志、录像、模型权重和评估报告。只有实际生成的文件才会出现在列表中。

按页面提供的按钮下载所需文件；指标曲线可导出 PNG 或 SVG，评估报告可导出 JSON。下载需要有效登录及该 Run 的读取权限，受保护的链接不能作为公开下载地址分享。

下次打开同一平台并登录，即可继续查看自己的课程和历史记录。服务维护与数据备份见[部署说明](deployment.md#日常启停)。
